
# Erzeugung der Agenda Dateien

Die Agenda Dateien in diesem Verzeichnis können mit einem **Unit-Test** erzeugt werden:

```
CourseSS26Tests.canScheduleCourseDays()
```

Dazu muss der folgende **Renderer** genutzt/aktiviert werden:

```
AgendaFileRenderingStrategy
```

Der Test im Projekt `course-manager` erzeugt diese `txt` Dateien, die zur Aktualisierung der Kursinhaltsdokumentation hierher kopiert werden müssen!
