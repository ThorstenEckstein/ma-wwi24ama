== KI in der Softwareentwicklung

* Aktuelle KI-Tools:
  - GitHub Copilot
  - ChatGPT
  - Amazon Q Developer
  - Amazon CodeWhisperer

* Einsatzgebiete:
  - Verstehen von unbekanntem Code
  - Code-Generierung und -Vervollständigung
  - Automatisierte Tests
  - Code-Review und Qualitätssicherung
  - Erstellung von technischer Dokumentation, z.B. JavaDoc


=== Technische Voraussetzungen

* **IDE:** IntelliJ IDEA mit KI-Plugins
* **KI-Tools:** Zugang zu GitHub Copilot oder ähnlichen Tools
* **Java:** JDK 17 oder höher
* **Testing:** JUnit 5
* **Build-Tool:** Maven


=== KI im Kontext Zugbetrieb

* *Praxisbeispiel:* Intelligente Zugdisposition
  - Predictive Maintenance für Züge
  - Optimierung von Fahrplänen
  - Anomalieerkennung in Sensordaten

* *Fallstudie:* Deutsche Bahn - KI für Pünktlichkeitsprognosen

=== Ethik & Best Practices

*Verantwortungsvoller KI-Einsatz*

* Bias und Fairness: Diskriminierung in Algorithmen vermeiden
* Transparenz: Nachvollziehbarkeit von KI-Entscheidungen
* Datenschutz: DSGVO-konforme KI-Implementierung

*Qualitätssicherung*

* Grenzen von KI-generiertem Code erkennen
* Notwendigkeit menschlicher Überprüfung
* Testing-Strategien für KI-integrierte Systeme


=== Experimente: "Intelligentes Zugüberwachungssystem"

**Szenario:** Entwicklung eines KI-gestützten Systems im Rahmen der Echtzeitüberwachung von Zügen

*Mögliche Experimente*:

. *Anomalieerkennung*: Implementierung eines Algorithmus zur Erkennung ungewöhnlicher Zugbewegungen
. *Verspätungsprognose*: Entwicklung eines Modells zur Vorhersage von Zugverspätungen
. *Automatisierte Disposition*: KI-gestützte Umleitung bei Störungen
